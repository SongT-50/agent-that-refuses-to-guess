An agent that refuses to guess

오늘 이 품목, 어느 도매시장에 내면 유리한가 — 근거가 모자라면 답하지 않는다.

Which wholesale market paid more for your crop today. When the evidence is thin, it says so instead of guessing.

How it works · Built on AWS Strands Agents SDK. The model reads your question and picks a tool. The tool computes the verdict deterministically and writes the sentence you read. If the right tool never ran, the agent refuses.

모델은 도구를 고르고, 도구가 판정과 문장을 쓴다. 판정은 코드에 있다.
